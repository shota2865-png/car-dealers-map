# 完全AI動画システム v2

撮影しない。音声も映像もすべて生成する構成の仕様です。
[`MASTER_BUILD_PROMPT.md`](MASTER_BUILD_PROMPT.md) を、
`yt-econ` を含むリポジトリのルートで起動した Claude Code に貼ってください。

## なぜ v1（撮影編集）を使わないか

`../shota-video-editor/` は撮影素材を前提にした設計です。
完全AIでは因果が逆転するため、あちらの Phase 2〜3 がまるごと不要になります。

| | 撮影編集（v1） | 完全AI（v2） |
|---|---|---|
| 音声 | 既にある | 台本から作る |
| タイムコード | WhisperX で推定（ズレる） | **所有している**（誤差ゼロ） |
| 最初の工程 | 素材を削る | 画面を作る |
| 最大の敵 | 失敗テイク | **画面が持たないこと** |

不要になるもの: WhisperX / 無音スナップ / リテイク検出 / フィラー削除 /
rough cut とそのロック。

v1 は削除していません。後で顔出しをする気になったときに使えます。

## この設計の勝負どころ

**人がいない画面を8〜10分持たせること。** 他が全部よくても、ここで負けます。

そのため「6秒ルール」を**気をつける努力目標ではなく、機械が検査する制約**に
しています。画面上で何も変化しない時間が6秒を超えたら QC が critical で止める。
変化イベントは AI の自己申告ではなく、シーン定義からコードで導出します
（申告させると平気で嘘をつくため）。

ゆっくりズームは変化として数えません。あれを流し続けても持ちません。

## 実装の優先順位

**Phase 1（Scene Planner）と Phase 4（Remotion）が本体です。**
AI画像・AI動画はその上の飾りなので、順番を逆にしないでください。
生成AIが1つも使えなくても、図表とモーションテキストだけで動画が完成する
構成にしてあります。

## コストの上限

先に上限機構を作らせています（Phase 2）。全編をAI動画で埋めると
1本あたり3,000〜30,000円、月60本で月18万〜180万円になり成立しません。

現実的な配分は **1本あたり約700円 / 月60本で約4万円**。
AI動画は1本あたり最大6カット、残りはAI画像とモーショングラフィックで作ります。
予算超過時は例外を投げず、**より安い種別に降格**させます
（パイプラインを止めるより、絵が地味になるほうがまし）。

## 検証済みの前提

このリポジトリの環境で、次は実機確認しています。

- yt-econ が 1920x1080 / 30fps / AAC の mp4 を出力する（日本語字幕焼き込み込み）
- Remotion 4.x が導入でき、既存の Chromium を指定してレンダリングできる
- 日本語フォントを `delayRender()` で待てば豆腐にならない

未検証（あなたの環境で確認が要るもの）:

- 画像・動画生成サービスの API と実コスト（サービスを固定していません）
- Remotion のフォント読み込みが 4K・長尺で安定するか
