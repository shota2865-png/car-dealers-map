muraiclip uploader

muraiclip uploader は、YouTube チャンネル「むらいクリップ【切り抜き】」（@maxmuraiclip）の運営者が、自分のチャンネルに動画を予約投稿するために使っている個人用のツールです。

できること

  • 運営者自身が作成した切り抜き動画（YouTube ショート）を、運営者自身の YouTube チャンネルにアップロードし、公開日時を予約します。
  • 投稿先が運営者のチャンネルであることを確かめるために、チャンネルの ID を読み取ります。

使う人

このツールを使うのは運営者本人だけです。一般の方に配布・提供しているサービスではありません。

Google アカウントへのアクセス

このツールは YouTube Data API を使い、運営者が許可した自分の YouTube アカウントに対してだけ、動画のアップロードとチャンネル情報の読み取りを行います。詳しくは プライバシーポリシー をご覧ください。
