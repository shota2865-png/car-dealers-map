# Shota Video Editor — Master Build Prompt

撮影済みの素材を、Claude Code が FFmpeg / WhisperX / Remotion を呼び出して
編集するシステム。その**システム自体を構築させるためのプロンプト**が
[`MASTER_BUILD_PROMPT.md`](MASTER_BUILD_PROMPT.md) です。

## 使い方

1. このシステムを置きたい空ディレクトリを作る
2. そこで Claude Code を起動する
3. `MASTER_BUILD_PROMPT.md` の `=== PROMPT START ===` から
   `=== PROMPT END ===` までを貼り付ける
4. Phase 1 が終わったら止まるので、報告を確認してから次へ進ませる

一度に全部作らせません。**7フェーズに分割し、各フェーズの末尾に
受け入れテストを置いています。** テストが通るまで次へ進まない構成です。

## このリポジトリの yt-econ との関係

別物です。用途が逆方向を向いています。

| | yt-econ | Shota Video Editor |
|---|---|---|
| 入力 | テーマだけ（素材なし） | 撮影済みの素材 |
| 音声 | 合成音声 | 本人の声 |
| 映像 | 生成した図表・カード | 撮影映像 + グラフィック |
| 人手 | ゼロ（無人運転） | 撮影 + 3回の承認 |
| 向く用途 | 毎日2本の量産 | 顔出しの主力コンテンツ |

**両方回すのが現実的です。** yt-econ で本数と検索面を取り、
Shota Video Editor で「この人から聞きたい」を作る。

共有できるもの:

- `assets/fonts/` — 同じ日本語フォント
- ブランド配色 — yt-econ の `visuals.palette` と
  SVE の `presets/brand.json` の `colors` を揃える
- 字幕の分割ルール — yt-econ の `src/ytecon/subtitles.py` の
  日本語折り返しロジックはそのまま流用できる
- 音声のラウドネス — yt-econ の `render.py` が使っている
  `loudnorm=I=-14:TP=-1.5:LRA=11` は同じ値でよい

## 出典の区別

このプロンプトの構成は、あなたが3本の動画から再構成した仕様が土台です。
それに対して**私が足した部分**は次のとおりです。参照動画に出てこない
判断なので、採否は分けて考えてください。

| 追加した内容 | 理由 |
|---|---|
| カット点の無音スナップ（`silence.py`） | WhisperX の日本語 word timestamp はかな単位アライメントで数十〜百数十ms ずれる。波形という一次情報で吸収しないと語頭が欠ける |
| `-c copy` 禁止・再エンコード前提 | 任意の時刻でのカットはキーフレームに吸われてずれる |
| グラフィックをアルファ付き別レイヤーで出す | 4K で毎回本編ごと再エンコードすると修正が回らない |
| BGM を固定 dB でなく LUFS 相対で決める | -23dB はその素材の声量に対する相対値であって普遍値ではない |
| フィラーの `conditional` 三条件 | 「あの本」の「あの」を消すと日本語が壊れる。無条件削除は危険 |
| リテイク検出を読みベースで正規化 | 漢字表記ゆれで類似度が落ちるため |
| rough cut のハッシュロック | グラフィックは秒数に貼り付くので、後から rough cut を変えると全部ずれる |
| Remotion のフォント読み込み待ち | `delayRender()` を挟まないとフォント未適用のフレームが出る |
| QC を全項目自動判定に限定 | 目視項目を混ぜると運用されなくなる |

HyperFrames は**私が API を検証できなかったため、仕様から外しています。**
推測で書くと嘘になるので、Remotion を本線にし、レンダラを差し替え可能な
インターフェースにしてあります。HyperFrames を使う場合は、
実際のドキュメントを確認したうえで `renderers/` に足してください。

## 最初に決めておくとよいこと

プロンプトを投入する前に、この2つだけ決めておくと手戻りが減ります。

1. **`presets/brand.json` の `speaker_zone`** — 画面のどこに顔が映るか。
   グラフィックの配置禁止領域になります。いつも同じ構図で撮るなら固定値でよい
2. **`presets/dictionary.json`** — よく使う固有名詞。
   WhisperX が確実に間違えるので、最初から入れておくと QC が静かになります
