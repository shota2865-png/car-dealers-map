# デザインシステム — 画面の寸法・色・角丸の下敷き

普段使っている 3 つのデザインシステムを、動画の画面づくりの土台にしています。
値は **`config/design_tokens.yaml`** にあり、`config/channel.yaml` の
`video.design` でプリセットを切り替えます。

| プリセット | 下敷き | 向いている場面 |
|---|---|---|
| `hybrid`（既定） | 3 つの合成 | 通常の動画。日本語の文字階層はデジタル庁、暗い背景の序列は Apple、角丸と面の段差は Material 3 |
| `digital_agency` | [デジタル庁デザインシステム](https://www.digital.go.jp/policies/servicedesign/designsystem) | 制度・統計を扱う回。行政資料のような堅さと読みやすさ |
| `apple` | [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines) | 黒地に大きな見出し、飾りを削いだ画面 |
| `material3` | [Material Design 3](https://m3.material.io/) | 色の役割で組む、モダンで柔らかい画面 |

## 3 つから何を借りたか

- **デジタル庁**: Noto Sans JP、8px グリッド、日本語本文の行送り 1.5〜1.7、
  文字と背景のコントラスト 4.5:1、見出し→本文→補足の文字階層
- **Apple HIG**: ダークモードの階層（背景 → 二次背景 → 三次背景）、
  ラベルの主・副・三次の明度差、太さと大きさだけで序列を作る、system カラー
- **Material 3**: 色の「役割」（primary / on-surface / outline）、surface の段差
  （container / container-high）、形の尺度（角丸 4/8/12/16/28）、強調イージング（300〜400ms）

## 何がトークンから決まるか

| トークン | 使う場所 |
|---|---|
| `colors.*` | すべてのカード・図表・サムネの配色（`assets.palette()`） |
| `type.*` | カードの文字サイズ（役割名で引く。`display_l` / `headline_m` / `body_l` / `label` …）、字幕の既定サイズ |
| `radius.*` | 出典カードなど角丸の大きさ |
| `stroke.*` | カードの枠線、文字の縁取り |
| `motion.fade_ms` | シーン切り替えのフェードの長さ |
| `common.grid` / `safe_margin` | 余白の単位、画面端からの余白 |

`visuals.palette` に個別の色を書けば、プリセットより優先されます（参考チャンネルの
実測色に寄せたいときはここ）。

## 注意

各システムの色コードは公式トークンの近似値です。この環境からは公式サイトに
アクセスできないため、厳密に合わせたい場合は公式のトークン一覧を見て
`design_tokens.yaml` の値を差し替えてください。文字サイズは UI 用の px を
1080p の動画（視聴距離が遠い）向けに約 2.5 倍しています。
