# スタイルバイブル — 「考えすぎる葦」型を経済解説に移植する

貼ってもらった分解（S01〜S09 / V01〜V05 / E01〜E05 / A01〜A05 / R01〜R05）は、
そのまま **`config/style_bible.yaml`** に入っています。感覚で寄せるのではなく、
このファイルを台本生成・シーン割り・BGM・サムネが読みます。
書き換えれば全工程が追従します。

## どこが何を読むか

| 分解の要素 | ファイルの場所 | 使うコード | 何が変わるか |
|---|---|---|---|
| S01〜S09 の 9 ブロック | `beats:` | `script.py`（プロンプト）/ `bible.py` | 台本の hook / proof / promise / 6 セクション / closing にブロックを割り当て、順序を固定 |
| リサーチの木 R01〜R06 | `research_lenses:` | `script.research_tree()` | 台本の前に「説明できる視点」を集めて 2〜3 個採用。結果は `script.json` の `research` に残る |
| Semantic Cut（E01） | `editing.semantic_cut_words` | `scenes.chunk_lines()` | でも／しかし／つまり… で始まる文の直前で画を切り替える。台本側にもその語で転換文を始めるよう指示 |
| 寄り・引き・横移動（E02〜E04） | `editing.motions` | `render.render_segment()` | 写真の動きを順に回す |

| 語りの温度 | `narration:` | `script.py` | 「みんなこんにちは！」を禁止し、知的好奇心を煽る文を優先 |

## 元の分解から変えたところ（このチャンネル向けの翻訳）

- **題材**: 心理学・社会学 → **経済学のレンズ**（行動経済学 / マクロ / ミクロ・産業 / 制度・歴史 / 統計 / 反論）。
  「日常の違和感 → 自分ごと化 → レンズ → 意外な説明 → 別視点 → 生活へ戻す」のループは同じ。
- **声**: 落ち着いた人間のナレーション → **ずんだもん**。温度（Calm + Intellectual）は保ち、
  口調だけ「のだ」調。画面の文字は標準語のまま。
- **視聴者**: 20〜30 代ビジネスパーソンに向けて話し、中身は小5に伝わる水準。
  そのため S09 は余韻で閉じつつ、「給料・買い物・働き方」への一言を必ず残す。
- **文の長さ**: 合成音声なので 1 文 20〜30 字（実測に基づく）。

## 立ち絵（ずんだもん）の置き方

**坂本アヒル様の「ずんだもん立ち絵素材」（PSD 版）にそのまま対応しています。**
zip を `~/Downloads` に置いて `素材をそろえる.command` を実行するか、展開したフォルダを
`assets/character/` の下に置くだけです。PSD のレイヤーから
「いつもの服 + 基本の腕 + むふ（口）+ 普通目 + 普通眉」を選んで合成し、
口は むふ → ほあ → ほあー の 3 段階で口パク、まばたきは UU を使います。
差分を変えたいときは `config/channel.yaml` の `character.parts`（例 `{服装1: "制服", 右腕: "指差し"}`）、
`character.mouth`、`character.blink`。クレジット「立ち絵：坂本アヒル 様」は readme から自動で入ります。

### 図解を出す（言葉だけで説明しない）

「タイトルだけ出て言葉で説明される」を無くすため、台本の各セクションに `diagrams` を 1〜3 個書かせます。
種類は 5 つ: `flow`（A→B→C の因果・順番）、`compare`（A vs B の表）、`balance`（数字の差し引き）、
`steps`（番号つきの手順・条件）、`table`（項目と値の一覧）。話している文（after_sentence）の位置で
文字カードより優先して出ます。古い台本には `ensure_diagrams()` で後付けできます。

### 画面の文字は「体言止め」

見出し・箇条書き・テロップ・文字カードは、ナレーションの文をそのまま出さず名詞で止めます。
発言は 発言者「引用」（例: 連合「1990年代前半以来の水準」）、数字は
「実質賃金がマイナスの月が26か月連続」＋出典行「— 毎月勤労統計調査（厚生労働省）」の形です。
台本の各セクションに `cards`（text / source / after_sentence）として LLM が書き、
古い台本には `ensure_cards()` で後付けできます。カードが無い場面は語尾を落として体言止めに寄せます。

### 表情を変える（ゆっくりMovieMaker の「表情切り替え」と同じ考え方）

台本の文頭に `[驚]` `[笑]` `[困]` `[考]` `[指]` `[怒]` と書くと、その一文のあいだだけ
右下の立ち絵の表情（目・眉・腕）が変わります。音声には読まれず、字幕にも出ません。
台本生成のプロンプトにも「1 セクションに 1〜2 回」の指示を入れてあるので、普段は自動で付きます。
差分の組み合わせは `config/channel.yaml` の `character.expressions` で変えられます。
話しているコマは `character.bob_px`（既定 8px）だけ上に動き、喋っている感じが出ます。

### 効果音

`assets/sfx/POP.mp3` のように種類名（POP / CLICK / WHOOSH / IMPACT / COMEDY / ERROR / RISER / TRANSITION）
のファイルを置くと、台本の `sounds` の位置で鳴ります（章の頭には TRANSITION）。
最小間隔 5 秒・1 分に 8 個までは `config/style_semantics.json` の値です。
Artlist の SFX からは `素材をそろえる.command` が 8 種類を落として振り分けます。合成音は使いません。

### フォルダ形式（ゆっくりMovieMaker4 の動く立ち絵）の場合


ゆっくりMovieMaker4 の「動く立ち絵」形式（`体/ 顔/ 口/ 目/ 眉/ …` のフォルダ、
`00.png` が基本・`00.0.png, 00.1.png…` がコマ）にそのまま対応しています。

1. 配布フォルダを `assets/character/` の下にフォルダごと置く
2. 使う差分を選ぶなら `config/channel.yaml` の `character.parts`（例 `{目: "00", 口: "00", 眉: "01"}`）
3. `character.credit` に配布元の指定どおりのクレジットを書く（概要欄に自動で入る）

口のコマ（`口/00.0.png` など）から閉・半開・開の 3 段階、目のコマから瞬きを合成して使います。
