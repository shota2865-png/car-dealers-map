# どこで動かすか

「Colab は閉じると消える」「自分のパソコンは準備に1〜2時間」——
どちらも穴が大きい、という指摘は正しいです。実は選択肢は4つあります。

| | 準備 | 消える？ | 毎日自動 | 費用 | 向いている段階 |
|---|---|---|---|---|---|
| Colab（そのまま） | 不要 | 閉じると消える | × | 無料 | 1回だけ試す |
| **Colab + Google Drive** | 不要 | **消えない** | × | 無料 | 何度か試す |
| **GitHub Actions** | 設定画面で30分 | **消えない** | **○** | 無料枠内 | **本番運用** |
| 自分の Mac | **10分**（VOICEVOX アプリ＋ダブルクリック） | 消えない | △（手動） | 無料 | Colab が不安定なとき・手元で確認したい人 |

## 結論

**お試し → Colab + Drive か Mac、本番 → GitHub Actions。**
Mac 版は `mac/ytecon_mac.zip` を展開して `動画をつくる.command` を
ダブルクリックするだけです（下記）。

---

## Colab + Google Drive

Colab が閉じると消えるのは「Colab の中」だけです。Google Drive に
道具を置いておけば残ります。ノートブックは最初から Drive を使う
設定にしてあります（`USE_DRIVE = True`）。

- 初回: 初回15〜20分・2回目以降8分ほど（1GB の音声エンジンを Drive に保存）
- **2回目以降: 3〜5分**（Drive から読むだけ）

これで「毎回20分待つ」は消えます。残るのは「▶ を自分で押す」ことだけ。

---

## 自分の Mac（Colab がうまくいかないとき）

1. VOICEVOX 公式サイトから Mac 版アプリを入れて、開いておく
   （初回は「開発元を確認できない」と出るので、システム設定 → プライバシーとセキュリティ → 「このまま開く」）
2. `mac/ytecon_mac.zip` を展開し、中の **`動画をつくる.command`** をダブルクリック
   - 同じく初回は「このまま開く」が要る。あるいはターミナルで `bash 動画をつくる.command`
   - 初回だけ Python の部品を入れるので 3〜5 分。以後は動画を作る時間だけ
3. できた mp4 は `out/日付_時刻/video.mp4`。終わると Finder が自動で開く

素材（Artlist の動画・曲、ずんだもんの立ち絵）は **`素材をそろえる.command`** をダブルクリックすると
まとめて取り込めます（[`Artlistの使い方.md`](Artlistの使い方.md)）。

台本を差し替えるときは、同じフォルダの `script.json` を上書きするか、
`bash 動画をつくる.command 別の台本.json` のように渡す。
VOICEVOX アプリを開いていなければ、自動で代替の声になる（画質などは同じ）。

---

## GitHub Actions（本番はこれ）

**GitHub のサーバーで動きます。** あなたのパソコンにも Colab にも
何も要りません。設定は全部ブラウザの画面で済みます。

- 決めた時刻（朝6時・夕方6時）に勝手に動く
- ずんだもんの音声エンジンも自動で立つ（コンテナとして横に起動）
- 台本生成は **Claude のサブスクの枠**で行う（従量課金なし）
- できた動画は YouTube に予約投稿される

ワークフローは `.github/workflows/daily-upload.yml` にすでに入っています。

### 設定するもの（1回だけ）

GitHub のリポジトリページ → **Settings** → **Secrets and variables** →
**Actions** → **New repository secret** で、次を登録します。

| 名前 | 何か | 取り方 |
|---|---|---|
| `CLAUDE_CODE_OAUTH_TOKEN` | Claude サブスクの長期トークン | 下記 |
| `YOUTUBE_CLIENT_ID` | YouTube 投稿の認証 | Google Cloud Console |
| `YOUTUBE_CLIENT_SECRET` | 同上 | 同上 |
| `YOUTUBE_REFRESH_TOKEN` | 同上 | `scripts/auth_youtube.py` |
| `PEXELS_API_KEY` | 写真素材（任意） | pexels.com/api |

#### CLAUDE_CODE_OAUTH_TOKEN の取り方

これだけ、手元のパソコンで Claude Code を1回動かす必要があります。
（環境を作るのではなく、トークンを発行するだけ。5分です）

```bash
npm install -g @anthropic-ai/claude-code   # Node.js が無ければ先に nodejs.org から
claude setup-token
```

ブラウザが開いて Claude にログインすると、トークンが表示されます。
それを `CLAUDE_CODE_OAUTH_TOKEN` として GitHub に登録してください。

> これは「Claude のサブスクに入っている人」向けの仕組みです。
> サブスクではなく API キーで使っている場合は、代わりに
> `ANTHROPIC_API_KEY` を登録し、ワークフローの
> `YTECON_LLM_PROVIDER: claude_code` を `api` に変えます（従量課金）。

#### YouTube の認証

Google Cloud Console で OAuth クライアント（デスクトップ）を作り、
`scripts/auth_youtube.py` を1回実行して refresh token を得ます。
手順は `yt-econ/README.md` の「鍵を入れる」にあります。
**これも自分のパソコンで1回だけ**です。

### 動かし方

登録が済んだら、GitHub の **Actions** タブ → 「毎日2本を自動生成して投稿」
→ **Run workflow** で手動実行できます。最初は `upload` を **false** にして、
できた mp4 を成果物（Artifacts）からダウンロードして確認するのが安全です。

問題なければ何もしなくても、毎日朝6時と夕方6時に動きます。

### 費用の目安

GitHub Actions はプライベートリポジトリで**月2,000分まで無料**です。
1本あたり15〜20分かかるので、1日2本 × 30日 = 60本 × 20分 = 1,200分。
無料枠に収まります。超えそうならリポジトリを公開にすれば無制限です
（コードが見えるだけで、鍵は Secrets なので見えません）。

### まだ検証できていないこと

Claude Code を GitHub Actions 上で `-p` モードで動かす部分は、
こちらの環境からは試せていません。初回実行で止まったら、
Actions のログ（赤い ✕ のところ）を貼ってください。直します。

## 自分のパソコン

上の2つで足りるので、最初は不要です。
「手元で台本を直しながら細かく作りたい」段階になったら検討してください。
そのときは `yt-econ/README.md` の手順で1〜2時間です。
