# 収益化ロードマップ — 目標を数字で検算する

> 結論を先に書きます。
> **「1ヶ月で5万円」は、YouTube広告収益だけでは制度上到達できません。**
> 3ヶ月20万円も、広告単独ではかなり厳しい水準です。
> ただし **年内50万円は、設計を変えれば射程に入ります。**
> 以下、なぜそうなるかと、どう組み替えるかを書きます。

---

## 1. なぜ1ヶ月目に5万円が出ないのか

YouTubeパートナープログラム（YPP）の参加条件:

| 条件 | 必要量 |
|---|---|
| チャンネル登録者 | 1,000人 |
| 直近12ヶ月の公開長尺の総再生時間 | 4,000時間 |
| 審査 | 申請後およそ数日〜1ヶ月 |

**この条件を満たすまで、広告収益は1円も発生しません。**
4,000時間 = 240,000分。1本を平均4分見てもらえるとすると、
**のべ6万回の視聴**が要ります。1日2本・月60本なら、
1本あたり平均1,000回再生が1ヶ月で必要という計算です。

新規チャンネルの1ヶ月目に、全60本が平均1,000回に届くことは、
まず起きません。実感値として初月は1本あたり数十〜数百回です。

さらに経済/ニュース系の日本語チャンネルのRPM（1,000再生あたりの収益）は
おおよそ **200〜600円**。仮にYPPに通っていたとして、月5万円には
**月間10万〜25万回再生**が必要です。

### つまり
- 1ヶ月目の現実的な目標は「収益」ではなく **YPP要件への到達度**
- 5万円という数字は、**3〜4ヶ月目に置くべき目標**

---

## 2. 組み替えた計画

目標額は変えず、**達成手段を広告以外にも広げます**。
広告収益は「あとから効いてくる複利」、それ以外は「早く立ち上がる直販」です。

### 月1（10月）— 収益 0〜5,000円 / 目標は「土台」

| 指標 | 目標 |
|---|---|
| 投稿 | 60本（1日2本） |
| 登録者 | 300〜600人 |
| 総再生時間 | 500〜1,200時間 |
| 収益 | 0〜5,000円（アフィリエイトのみ） |

やること:
- **サムネとタイトルのA/Bを回す。** 初月の伸びはほぼここで決まります。
  再生数の低い回のサムネを1週間後に差し替えて、変化を記録する。
- **Shortsを併走させる。** 長尺の山場30〜60秒を切り出して1日2本。
  Shorts は登録者を集める効率が長尺の数倍あります。
  （※Shortsの再生時間は長尺4,000時間には算入されません。登録者集め専用と割り切る）
- 概要欄に書籍アフィリエイト（Amazonアソシエイト）を置く。
  経済入門書は単価が低いので、期待値は月数千円です。

### 月2（11月）— 収益 5,000〜30,000円

| 指標 | 目標 |
|---|---|
| 登録者 | 1,000人到達 → **YPP申請** |
| 総再生時間 | 累計2,500〜4,000時間 |
| 収益 | アフィリエイト + 審査通過すれば広告が発生開始 |

### 月3（12月）— 収益 30,000〜100,000円

YPP通過が前提。月間20万回再生まで積み上がれば、広告で4〜10万円。
ここに下記を足して **12月単月で20万円**を狙います。

### 年内50万円の内訳（累計、12月31日まで）

| 収益源 | 見込み | 根拠 |
|---|---|---|
| YouTube広告（11〜12月） | 5〜15万円 | YPP通過後の2ヶ月ぶん |
| 企業案件（12月に1〜2件） | 10〜30万円 | 登録者1万人規模で1件5〜20万円。証券/家計簿アプリ/転職は単価が高い |
| 自作教材（noteやBrainで販売） | 5〜15万円 | 「経済ニュースの読み方」3,000円 × 30〜50本 |
| アフィリエイト | 2〜5万円 | 書籍・証券口座 |
| **合計** | **22〜65万円** | 中央値で40万円前後 |

**50万円に届くかは「企業案件が取れるか」でほぼ決まります。**
そして企業案件は登録者数より **「誰が見ているか」** で決まるので、
視聴者層（高校生〜20代ビジネスパーソン）が明確な本チャンネルは有利です。
月2から、概要欄に問い合わせ用のメールアドレスを必ず置いてください。

## 3. この計画が崩れる最大のリスク

### リスク1: 収益化審査に落ちる（最重要）

YouTubeの **「再利用されたコンテンツ」** ポリシーは、
AI音声を載せただけ・独自の解説や価値の付加がないチャンネルを弾きます。
2024年以降、AI量産チャンネルの審査は明確に厳しくなっています。

本パイプラインが審査対策として組み込んでいるもの:

| 仕掛け | 効果 |
|---|---|
| ファクトチェック工程（`script.fact_check`） | 出典の明示。一次情報への言及が「独自の調査」の証跡になる |
| 図表の自動生成（matplotlib） | 「オリジナルの視覚資料」の付加 |
| 重複排除（`topics.dedupe_*`） | 同じ内容の使い回しを防ぐ |
| 概要欄の出典欄・注意書き | 情報源の透明性 |
| AI音声使用の明記 | 開示義務への対応 |

**これらを高速化のために切らないでください。** 切った瞬間に
「量産チャンネル」の見た目になります。

さらに、審査を通すために **人間の手を1日5分だけ入れる**ことを強く勧めます:
- 生成された台本の冒頭だけ読んで、事実がおかしくないか確認する
- 月に数本、自分の意見・体験を1段落だけ追記する

これで「独自性」の証跡が段違いになります。完全無人と、
1日5分の目視の差は、審査結果ではおそらく決定的です。

### リスク2: 毎日2本が品質を殺す

1日2本 = 月60本は、**チャンネルの寿命より先に視聴者の信頼を削る**危険があります。
経済系は1本の誤りで信頼が飛ぶジャンルです。

推奨: **最初の2週間は1日1本**にして、当たるフォーマットを見つけてから
2本に増やす。`config/channel.yaml` の `pipeline.videos_per_day` で変えられます。

### リスク3: 8〜10分という尺

YPPの4,000時間を稼ぐには長い動画が有利ですが、
新規チャンネルでは **視聴維持率が落ちて推薦が回らなくなる**ほうが痛いです。
最初の1ヶ月は6〜8分に短くして維持率を稼ぎ、
数字が安定してから10分に伸ばすのが定石です。

```yaml
video:
  target_minutes_min: 6.0   # 立ち上げ期
  target_minutes_max: 8.0
```

## 4. 毎週やる計測（これをやらないと改善が効かない）

YouTube Studio で毎週見る数字は4つだけで足ります。

| 指標 | 見る場所 | 悪いときの打ち手 |
|---|---|---|
| インプレッションのクリック率 | アナリティクス→リーチ | 4%未満ならサムネとタイトルを作り直す |
| 平均視聴時間 | エンゲージメント | 尺の40%未満なら台本の前半を削る |
| 最初の30秒の離脱 | 視聴者維持率グラフ | 急落するなら hook を書き換える |
| 登録者の増えた動画 | 視聴者 | そのテーマの派生を3本作る |

`config/channel.yaml` の `channel.tone` と `topics.evergreen_seeds` に
この結果を反映させていくのが、このパイプラインの正しい育て方です。

- [ ] 10/下旬: 1日2本に増やす。登録者300人
- [ ] 11/中旬: 登録者1,000人 + 4,000時間 → YPP申請
- [ ] 11/下旬: YPP通過。noteで教材を1本公開
- [ ] 12/上旬: 登録者5,000人。企業案件の問い合わせ窓口を整備
- [ ] 12/末: 単月20万円 / 累計40〜50万円

---

**この計画の要点をもう一度。**
1ヶ月目に5万円は出ません。制度上そうなっています。
そのぶん、**1ヶ月目にYPP要件へ最短で到達する**ことに全部を振る。
そして収益源を広告だけに賭けない。この2点で、年内50万円は残ります。
