# BGM の用意

何も置かなくても、リラックス系のパッド音を自動で合成して鳴らします
（`render.bgm.file` が空のとき）。ただしこれは**仮の音**です。
本番はフリー音源に差し替えることを勧めます。

## 置き方

1. 下のサイトから mp3 / wav を1曲ダウンロード
2. `yt-econ/assets/bgm/` に置く
3. `config/channel.yaml` の `render.bgm.file` にファイル名を書く
   （空のままでも、フォルダに1曲あればそれを使います）

Colab で作る場合は、zip を作る前に置いておけば同梱されます。

## 無料で商用利用できる日本の定番

| サイト | 向いている曲調 | 注意 |
|---|---|---|
| DOVA-SYNDROME | ニュース系・落ち着いた BGM が豊富 | 曲ごとの利用規約を確認（ほぼ商用可・クレジット任意） |
| 甘茶の音楽工房 | やわらかい・リラックス系 | 商用可・クレジット任意 |
| BGMer | 解説動画向けの軽い曲 | 商用可・クレジット任意 |
| YouTube オーディオライブラリ | ジャンル検索が楽 | YouTube Studio 内。「帰属表示不要」で絞る |

検索の目安: 「ニュース」「解説」「落ち着いた」「アンビエント」「lo-fi」。

## 選ぶときの基準

- **歌なし**。声とぶつかる
- **展開が少ない**曲。サビで急に大きくなる曲は、ダッキングしても耳につく
- **テンポ 70〜100** くらい。速いと焦って聞こえる
- 3〜5分あれば十分（自動でループします）

## 音量の仕組み

`render.bgm.volume_db: -8` が既定です（声の間で声より約12dB小さい。目立つなら -11、寂しいなら -6）。
さらに `ducking: true` で、声が乗っている間は自動で BGM を下げます。
最終的に全体を YouTube の基準（-14 LUFS）に揃えるので、
BGM を大きくしすぎると声のほうが小さく聞こえます。
「BGM が目立つ」と感じたら -14 〜 -16 に、「寂しい」なら -8 に。
