# ブラウザだけで実測する

パソコンに何もインストールせずに、参考チャンネルの数値を測れます。

## やり方

1. https://colab.research.google.com/ を開く（Googleアカウントでログイン）
2. 左上の「ファイル」→「ノートブックをアップロード」
3. このフォルダの **`参考チャンネル実測.ipynb`** を選ぶ
4. 出てきた画面の左にある **▶（再生ボタン）** を押す
5. 10〜20分待つ
6. 一番下に出た結果をコピーして Claude に貼る

途中で「警告: このノートブックは Google が作成したものではありません」と
出たら「このまま実行」を押してください。

## アップロードが分からない場合

`measure.py` の中身を全部コピーして、Colab の空のセルに貼り付けて
▶ を押しても同じです。

## 測る本数を変えたい

スクリプトの上のほうにある

```python
VIDEOS_PER_CHANNEL = 3
```

の数字を変えてください。増やすほど正確になりますが、時間がかかります。

```python
DEEP = True
```

を `False` にすると映像を落とさなくなり、数分で終わります。
ただしカット頻度と配色は測れません（話速と語り口だけになります）。

## 何が出るか

- 尺・話速（文字/分）・1文の長さ
- **カット頻度（回/分）・1ショットの長さ（秒）** ← いちばん重要
- 6秒を超えるショットの割合
- 支配色
- チャプター数
- 字幕のサンプル

# 動画を1本つくる（Colab）

## 環境とは

プログラムが動くのに必要な道具が揃った場所のことです。この動画づくりには
こういう道具が要ります。

| 道具 | 役割 |
|---|---|
| Python | プログラム本体を動かす |
| ライブラリ | 画像や図を作る部品 |
| ffmpeg | 音と絵をつないで動画にする |
| VOICEVOX | ずんだもんの声を作る |
| 日本語フォント | テロップを描く |

これらを自分のパソコンに入れる作業が「環境を作る」です。

## Colab とは

Google が貸してくれる、ブラウザで使えるパソコンです。
上の道具の多く（Python・ffmpeg など）が最初から入っています。
さっきチャンネルを実測したときに使ったものと同じです。

|  | Colab | 自分のパソコン |
|---|---|---|
| 最初の準備 | 不要 | 1〜2時間かかる |
| 費用 | 無料 | 無料 |
| 毎回の待ち時間 | 15〜25分（毎回入れ直し） | ほぼゼロ |
| 閉じたら | **全部消える** | 残る |
| 毎日自動で回す | できない | できる |
| 向いている使い方 | お試し・確認 | 本番運用 |

**まず1本見てみる段階では Colab、毎日2本を自動で回す段階では
自分のパソコン**、という使い分けになります。

## 手順

1. `ytecon_colab.zip` と `動画をつくる.ipynb` をダウンロードしておく
2. https://colab.research.google.com/ を開く
3. 「ファイル」→「ノートブックをアップロード」→ `動画をつくる.ipynb`
4. ▶ を押す
5. ファイルを選ぶ画面が出たら `ytecon_colab.zip` を選ぶ
6. 待つ
7. mp4 が自動でダウンロードされる

## 声について

`USE_VOICEVOX = True` ならずんだもんの声になりますが、1GBほど
ダウンロードするので時間がかかります。

`False` にすると軽い代替音声（機械的な読み上げ）で5分ほどで終わります。
**絵とテロップと流れを確認するだけなら、まず False で十分です。**
声は後から差し替えられます。

> VOICEVOX を Colab に入れる部分は、こちらの環境で検証できていません。
> うまくいかなかったら、表示されたメッセージを教えてください。
> なお失敗しても自動で代替音声に切り替わるので、動画自体は完成します。
