プライバシーポリシー

本ポリシーは、「おやすみ経済学 投稿ツール」（以下「本ツール」）が Google API サービスを通じて取得する情報の扱いを定めるものです。

1. 利用者

本ツールの利用者は、YouTube チャンネル「おやすみ経済学」の運営者本人のみです。一般の利用者を対象としたサービスではありません。

2. 取得する情報

  • 運営者自身の YouTube チャンネルへの動画投稿・編集に必要な認可情報（OAuth トークン）
  • 運営者自身のチャンネルおよび動画の公開統計（再生数、登録者数、視聴時間、平均視聴率）

視聴者個人を特定できる情報、他のチャンネルやユーザーのデータは取得しません。

3. 利用目的

  • 自作動画の予約投稿、サムネイル・字幕・再生リストの設定
  • 投稿計画の改善のための、自チャンネルの統計の確認

4. 保存と共有

認可情報は運営者が管理する GitHub リポジトリの暗号化された Secrets にのみ保存します。取得した統計は運営者の管理下にのみ保存し、第三者に提供・販売しません。

5. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から取得した情報の利用は、 Google API Services User Data Policy（限定的な使用の要件を含む）に従います。 また YouTube API サービスを利用しているため、YouTube 利用規約 および Google プライバシーポリシー が適用されます。

6. 認可の取り消し

運営者は Google アカウントのセキュリティ設定 からいつでも本ツールのアクセス権を取り消せます。
