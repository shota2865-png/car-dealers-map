おやすみ経済学 投稿ツール（oyasumi-keizai）

YouTube チャンネル「おやすみ経済学」の運営者が、 自分のチャンネルに動画を予約投稿し、自分のチャンネルの再生数を確認するために使っている内部ツールです。 一般向けのアプリではなく、利用者はチャンネル運営者本人のみです。

このツールがすること

  • 経済・お金・就活をテーマにした自作の解説動画（本編 1 本と Shorts 3 本／日）を、決めた時刻に予約投稿する
  • 投稿した動画にサムネイルと字幕を付け、再生リストに追加する
  • 自分のチャンネルの再生数・登録者数・視聴時間を 1 日 1 回読み取り、投稿計画に反映する

使用する YouTube API

YouTube Data API v3（videos.insert / videos.update / thumbnails.set / captions.insert / playlistItems.insert / videos.list / channels.list）と YouTube Analytics API（reports.query）。対象はすべて運営者自身のチャンネルです。

プライバシー・データの扱い

詳しくは プライバシーポリシー をご覧ください。第三者のデータは取得せず、 取得した自分のチャンネルの統計は運営者の管理するリポジトリ内にのみ保存します。
